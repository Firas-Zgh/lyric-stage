# Lyric Stage

Lyrics for a portable monitor standing upright, mirrored from an iPhone held sideways.

## Put it online (GitHub Pages)
1. Create a public repository, for example `lyric-stage`.
2. Upload every file in this folder to the repository root.
3. Settings > Pages > Build and deployment: Deploy from a branch, `main`, `/ (root)`. Save.
4. After a minute the app is at `https://<your-username>.github.io/lyric-stage/`.

## Install on the iPhone
Open the link in Safari, tap Share, then Add to Home Screen.
The app opens full screen from its icon and keeps working offline after the first launch.

Songs are stored on the device inside the app. Use Move songs > Copy library / Paste library
to bring songs over from the Claude version or to keep a backup.
